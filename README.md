# Hiring Progress Status Tracker 2025 (Interactive Dashboard using MS Excel)

## Project Objective
Create an interactive recruitment dashboard that tracks applications from sourcing to joining, so the HR team can see where candidates drop off, which sources and positions perform best, and speed up hiring for open positions.

## Dataset Used
Recruitment data with Candidate details, Position Applied, Department, Application Source (Naukri, LinkedIn, Referral, Consultant, Direct), Application Date (Month/Week), Stage Status (CV Screening, HR Assessment, Tech Interview 1, Tech Interview 2, Offered), and Final Status (Rejected, Dropped out, Offered, Joined).

## Questions (KPIs)
- How many positions are open and how many applications were received?
- How many candidates were rejected, dropped out, accepted offers and joined?
- What is the hiring percentage?
- How many candidates reach each stage of the hiring funnel?
- Which positions receive the most applications?
- Which source brings the most applications?
- What is the split of applications by final status?
- How do results change by month, week, department and position applied?

## Process
1. Verified the data for missing values, duplicates and anomalies and corrected them.
2. Made sure data types, formats and status values were consistent.
3. Created pivot tables for each KPI, the funnel, the source analysis and the position analysis.
4. Built the charts: KPI cards, applications by position (column chart), final status (donut chart), hiring funnel and applications by source.
5. Combined everything on one Dashboard sheet and added slicers (Month, Weekly, Department, Position Applied) to make it dynamic.
6. Organised the workbook into Dashboard, Summary, Data and Recruitment Progress sheets.

## Project Insights
- Rejections are about 61% of all applications (108 of 176), so most candidates are filtered out early.
- The funnel narrows sharply after CV screening (124 candidates), with only 15 moving to HR assessment, which points to a strong screening filter or a mismatch between sourced profiles and requirements.
- Naukri is the dominant source, bringing the vast majority of applications, while Referral is a distant second and LinkedIn, Consultants and Direct add very little.
- Applications are concentrated in a few positions (the top position alone has about 34 applications), while many positions get only 1 or 2.
- Drop-outs are low at about 7%, so candidates who enter the process mostly stay engaged.
- 12 candidates have joined (about 18%) against 9 open positions still to fill.

## Final Conclusion
To improve hiring, the HR team should tighten the job description and sourcing so that more profiles pass CV screening, and build the Referral and LinkedIn channels to reduce dependence on Naukri. Focus on the 9 open positions, especially those that get few applications, and shorten the time between interview rounds and offers to protect the offer acceptance rate. Use the slicers to review progress every week.
